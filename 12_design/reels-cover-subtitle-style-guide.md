# Reels Cover + Subtitle PNG Style Guide

این سند baseline تصویری Reelهای ASDEV است؛ برای اینکه Cover و Subtitleهای بعدی از صفر طراحی نشوند و خطاهای فارسی، RTL، شلوغی و ناهماهنگی با ویدیو تکرار نشود.

## 1) اصل اصلی

هر asset باید در **یک نگاه** سه کار انجام دهد:

1. متن فارسی دقیق و سریع‌خوان باشد.
2. با فضای همان Reel هماهنگ باشد، نه یک قالب عمومی تصادفی.
3. در موبایل و Grid اینستاگرام خوانا بماند.

> Design باید موضوع Reel را تقویت کند، نه اینکه برای خودش نمایش جداگانه اجرا کند.

---

## 2) استاندارد Cover ریلز

- بوم اصلی: `1080 × 1920`، نسبت `9:16`.
- Safe Zone بالا: حدود `210–270 px`.
- Safe Zone پایین: حداقل `310–350 px`؛ برای اطمینان بیشتر تا `450 px`.
- Safe Zone چپ: حداقل `60 px`.
- Safe Zone راست: حدود `84–120 px`.
- تیتر و سوژه اصلی تا حد ممکن در هسته مرکزی بمانند تا در Grid profile هم قابل‌تشخیص باشند.
- وقتی user می‌گوید «همه‌چی وسط‌چین»، hierarchy، تیتر، URL و لوگو همگی روی محور مرکزی قفل شوند.

### Cover hierarchy تأییدشده

1. Hook اصلی: بزرگ‌ترین عنصر.
2. Payoff / keyword: با رنگ متضاد یا badge.
3. Tool/logo/URL: کوچک‌تر و ثانویه.
4. Brand `ASDEV`: کوچک و کم‌مزاحمت.

### Cover نباید

- شبیه اینفوگرافیک شلوغ شود.
- ده‌ها icon و feature badge داشته باشد.
- تیتر را قربانی تصویر کند.
- متن ریز زیاد داشته باشد.
- در safe zone لبه‌ها گیر کند.

---

## 3) Subtitle PNG — قرارداد ثابت

Subtitleها باید **جداگانه** تحویل شوند؛ هر paragraph / beat یک PNG مستقل.

### الزامات فنی

- PNG با background شفاف واقعی.
- Canvas تا جای ممکن tight-crop باشد؛ فضای خالی زیاد ممنوع.
- paragraphها وسط‌چین باشند مگر user صریحاً راست‌چین بخواهد.
- RTL و ترتیب کلمات فارسی باید درست باشد.
- punctuation فارسی و فاصله‌ها بررسی شوند.
- متن دقیق user، بدون paraphrase ناخواسته.
- برای ترکیب فارسی/English، نام انگلیسی روی خط مستقل یا badge مستقل قرار بگیرد تا RTL به‌هم نریزد.

### اندازه و فرم

- متن 1 خطی: banner افقی کوتاه.
- متن 2 خطی: card فشرده، نه مستطیل خیلی بلند.
- متن 3 خطی یا بیشتر: به چند subtitle split شود؛ readability مهم‌تر از فشرده‌کردن همه‌چیز در یک PNG است.
- برای فضای خالی کنار پا/سوژه، cardها می‌توانند مربع‌تر و compact باشند.

### emphasis

در هر subtitle حداکثر 1 تا 2 keyword برجسته شود.

نمونه:

- `رایگان`
- `عکس`
- `همه`
- `سایت`
- `پرو`
- `جِمِنای`

Keyword می‌تواند رنگ متفاوت، underline brush، badge یا وزن بیشتر بگیرد؛ ولی کل جمله نباید چندرنگ و شلوغ شود.

## 4) Palette بر اساس ژانر Reel

| ژانر | Direction تأییدشده |
|---|---|
| Detective / Mystery / Gemini Live | deep navy / black + violet / magenta + electric blue؛ نور نئون کنترل‌شده، حس کارآگاهی/معمایی |
| Website builder / Z.ai | white + bright blue + clean UI cues؛ ساده، روشن، tech/productive |
| General AI tools / Duck.ai | black / charcoal + yellow + cyan/teal؛ strong contrast، bold creator-style |
| Skincare / beauty | warm cream / ivory + champagne gold + brown؛ premium, clean, soft |
| Clay / child / daughter | peach / cream / soft pink + warm 3D clay؛ playful, soft, cute |
| Future / Tehran 2120 | dark navy / purple / cyan neon؛ sci-fi subtitle feel، متن کم و سینمایی |
| Money / paid-vs-free hook | red / black یا yellow / black فقط وقتی داستان Reel واقعاً مالی/هزینه‌ای است |
| Telegram CTA | blue/cyan Telegram cue، ولی CTA نباید از Hook بزرگ‌تر شود |

### Rule

رنگ‌ها از خود Reel یا cover گرفته شوند. یک palette موفق از Reel قبلی نباید بدون دلیل روی موضوع کاملاً متفاوت کپی شود.

## 5) سبک‌های موفقی که در این چرخه تأیید شدند

### A. Detective / police / mystery subtitles

برای `گوشیتو می‌گرده؟` و ادامه Gemini Live:

- dark card / neon edge
- violet + blue highlights
- mystery iconography محدود
- bold Persian
- cinematic police/detective mood

یادگیری: نسخه‌های آخر بهتر از subtitleهای generic بودند چون **genre را منتقل می‌کردند**.

### B. Skincare premium subtitles

برای:

- `هر محصولی مناسب پوست نیست`
- `اول نوع پوست خودت رو بشناس`
- `بعد محصول درست رو انتخاب کن`
- `برای مشاوره، پیام بده`
- `raz.poost.javani`

Direction:

- ivory/cream glossy card
- thin gold border
- dark warm-brown Persian type
- icon کوچک مرتبط با پوست/قطره/مشاوره
- بدون neon و بدون tech styling

### C. Website / Z.ai

برای hook `پول نده، سایتتو رایگان بساز`:

- white/blue design-system look
- logo و URL محدود و واضح
- background با حال‌وهوای website builder
- cover هرچه خلوت‌تر شد، hook قوی‌تر شد

### D. Duck.ai / multi-AI Reel

آخرین direction subtitle:

- black + yellow + white
- 3D/glossy ولی ساده‌تر از poster
- paragraph center aligned
- exact copy در 4 asset مستقل

Canonical dialogue beats:

1. `پول اشتراک نده. حتی ثبت نام هم نکن!`
2. `چندتا هوش مصنوعی معروف رو رایگان یه جا داری`
3. `عکس هم می‌سازه.`
4. `اگه میخوایش: همه رو کامنت کن.`

## 6) قواعد فارسی و RTL — Quality Gate اجباری

قبل از تحویل هر PNG:

- [ ] متن دقیقاً با copy user مقایسه شده.
- [ ] حروف جابه‌جا نشده‌اند.
- [ ] کلمه جا نیفتاده یا اضافه نشده.
- [ ] فاصله و نیم‌فاصله باعث شکستن خوانایی نشده.
- [ ] علامت سؤال/تعجب در جای درست است.
- [ ] نام انگلیسی وسط جمله فارسی layout را خراب نکرده.
- [ ] paragraph center alignment یا right alignment طبق درخواست رعایت شده.

### Rule حیاتی

اگر image generator متن فارسی را خراب کرد، همان خروجی نباید صرفاً به خاطر طراحی زیبا قبول شود. **Persian exactness gate مقدم بر جلوه گرافیکی است.**

---

## 7) چیزهایی که user رد کرده یا باید کمتر استفاده شوند

- subtitleهای generic که فقط یک کادر ساده‌اند و حس موضوع ندارند.
- افکت بیش از حد برای subtitleهای روزمره.
- glow و neon روی موضوع‌های clean / skincare / website.
- assetهایی که چند subtitle را در یک تصویر بزرگ می‌چسبانند وقتی user جداگانه خواسته.
- background مشکی واقعی به‌جای transparency.
- canvas بزرگ با فضای خالی زیاد.
- متن اشتباه یا paraphrase شده.
- استفاده از کاراکتر، لوگو یا محصول اشتباه.
- cover شلوغ با featureهای زیاد وقتی user فقط تیتر + لوگو + URL خواسته.

---

## 8) نقاط قوت تثبیت‌شدهٔ سیستم ما

1. **Genre-aware design** — هر Reel visual language خودش را می‌گیرد.
2. **Hook-first hierarchy** — تیتر از همه‌چیز مهم‌تر است.
3. **Character continuity** — Rose و سایر characterها در محتواهای مرتبط قابل‌شناسایی می‌مانند.
4. **Reusable visual grammar** — card / badge / keyword highlight / icon system بدون کپی کورکورانه.
5. **Cross-channel recognition** — برای Discover سایت، از cover همان Reel یا adaptation نزدیک استفاده شود تا کاربرِ واردشده از Instagram محتوا را فوری بشناسد.
6. **Exact Persian QA** — متن فقط تزئین نیست؛ خودش deliverable است.
7. **Mobile-first** — طراحی برای خوانایی سریع در صفحه موبایل، نه نمایش دسکتاپ.

---

## 9) Workflow استاندارد Cover + Subtitle

1. ویدیوی واقعی Reel را inspect کن.
2. palette و lighting غالب را استخراج کن.
3. genre را مشخص کن.
4. copy دقیق را lock کن.
5. paragraph split را با user copy حفظ کن.
6. subtitle PNGها را جداگانه بساز.
7. RTL/text QA انجام بده.
8. cover را با hook-first hierarchy بساز.
9. safe-zone و Grid crop را بررسی کن.
10. اگر asset برای Discover سایت است، continuity با Instagram cover را حفظ کن.

---

## 10) Definition of Done

یک asset زمانی آماده است که:

- فارسی بدون خطا باشد.
- با Reel هماهنگ باشد.
- در موبایل سریع خوانده شود.
- از سوژه و UI اینستاگرام مزاحمت نگیرد.
- keyword hierarchy واضح داشته باشد.
- PNG subtitle جدا، transparent و قابل‌ادیت باشد.
- cover در Grid هم معنی خودش را از دست ندهد.
