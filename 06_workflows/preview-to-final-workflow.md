# Preview to Final Workflow

## Principle

Preview approval means **direction accepted**, not production-ready.

## Workflow

`Narrative PASS → Exact Copy → Visual Route → Foundation/Region/Bidi lock → Art Direction → Visual Gate → Preview Prompt → Render → Rendered Preview Gate → User Direction Review`

If direction is approved:

`Exact/Hybrid Final Production → Final Render Verification → production-ready`

## Exact Persian safety

Do not rely on generative image typography as the authoritative source of final Persian copy.

Preferred final modes:

- exact editable text layer;
- hybrid composition where generated visual assets are combined with exact typography;
- other deterministic text-rendering method.

## Preview review dimensions

User preview approval can accept:

- hierarchy;
- composition;
- visual metaphor;
- palette direction;
- density;
- family coherence.

It does not automatically approve:

- generated spelling;
- exact line breaks;
- final footer correctness;
- final export geometry;
- publication-ready text.
