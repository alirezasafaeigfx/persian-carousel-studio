# ASDEV Brand Architecture

## Architecture

`ASDEV Brand Core + Category Art Direction + Post-Level Variation`

The brand has deep invariants but variable surface execution.

## Stable layer

- systems-thinking posture;
- evidence discipline;
- Persian-first clarity;
- ASDEV signature;
- footer domain;
- production quality gates;
- truthful claims.

## Variable layer

Resolved per post:

- visual mode;
- palette family;
- typography strategy;
- layout family;
- image treatment;
- density;
- framing primitive;
- motif.

## Anti-template rule

Category is a territory, not a template. A category must never map mechanically to one color/font/layout combination.
