# Carousel Narrative System

## Goal

A carousel is a sequence of information gains, not a stack of disconnected slides.

## Level A contract

Before writing final copy, define for every slide:

- `Job`
- `Core message`
- `New information`
- `Reason to continue`
- `Transition`
- `Proof needed` when applicable

## Required narrative resolution

1. Audience start state
2. Audience end state
3. Core insight
4. Primary tension
5. Natural next action
6. 3+ genuinely different concept directions
7. Direction recommendation
8. Level A slide map
9. Narrative Gate

## Slide rules

- one primary job per slide;
- each slide must add information;
- no filler created only to hit a slide count;
- transitions should be semantic rather than artificial teasing;
- cover promise must be paid off by the body;
- early slides must make the topic and importance understandable.

## Narrative Gate

Check:

1. Core insight is clear.
2. Start and end states differ meaningfully.
3. Cover promise matches body.
4. Each slide has a unique job.
5. Each slide has information gain.
6. Sequence has logical dependency.
7. Transitions are meaningful.
8. Sensitive claims have proof/qualification.
9. No filler/duplicate slides.
10. CTA follows naturally from the end state.

Blocking failures include broken promise, duplicate/filler slides, missing proof for material claims, or unclear slide jobs.

Result:

`PASS | REVISE | INCOMPLETE`

If Narrative Gate is not PASS, Art Direction must not start.
