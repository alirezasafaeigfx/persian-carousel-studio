
`source / file → slide deck + infographic + audio output → sell the content-preparation service`

Public-facing truthfulness rule:

> The AI is the production tool; the income comes from providing useful work to a customer.

## 4. Google Flow production approach

The first attempt used a supplied AI-generated female portrait as a reference image.

Flow returned a policy-related generation failure.

Decision:

**drop the reference image entirely rather than repeatedly fighting the image-person policy filter.**

Final prompt strategy:

- no reference image;
- explicitly create a new original fictional AI-generated Iranian woman;
- stable medium-close eye-level shot;
- one uninterrupted 10-second recording;
- natural Iranian Persian;
- real silent pauses;
- no tool name in speech;
- zero generated subtitles / UI / logos / overlays;
- pink blazer + white blouse + thin round glasses + tied-back brown hair as the visual identity for this one Reel.

Promoted learning:

> If a nonessential portrait reference triggers Flow's person-image policy, removing the reference can be cleaner and more reliable than adding defensive wording to the prompt.

Do not infer that declaring an uploaded portrait `AI-generated` guarantees acceptance by Flow.

## 9. Learnings promoted from this cycle

### A. Income hook can be truthful

A strong money hook does not require a false promise.

Preferred structure:

`income desire → concrete service output → one CTA`

Avoid:

`AI pays you automatically` or `guaranteed earnings`.

### B. Explain the service, not the fantasy

The strongest ethical framing is:

> use AI to make a deliverable faster, then sell the useful service.

### C. Remove nonessential reference images when they create Flow friction

Reference-image continuity is valuable only when the identity itself matters.

For a one-off talking Reel, a prompt-defined fictional character can be the more robust production path.

### D. Cover simplification

When user feedback says a cover is busy, reduce **message count**, not only decorative elements.

The removed line was:

`با فایل مشتری`

The final cover returned to one dominant promise:

`با هوش مصنوعی پول دربیار`

### E. Keep subtitles in post

Persian dialogue graphics remain a manual editing asset, not a generated-video responsibility.
