## 1. Strategic hypothesis

The Reel intentionally uses the account's strongest combined mechanism:

`cost-saving hook + concrete utility + one-word CTA`

Primary objective:

- stop the swipe in the first 0–2 seconds;
- make the benefit understandable without technical explanation;
- create curiosity around access;
- keep the Reel short enough that Flow does not compress the speech into robotic delivery.

Tool/platform details are kept out of the spoken Reel and revealed in the caption/comment path.

Public-facing concept:

**Use Sora without paying for a separate Sora subscription.**

`Bing Video Creator`

## 3. Dialogue evolution

### Initial direction

The first script used `Sora 2` in spoken Persian.

Flow pronounced the number `2` badly.

### Corrective decision

The user explicitly requested that the number be removed from spoken dialogue rather than spending credits trying to force pronunciation.

This is an example of the existing rule:

`semantic simplification > pronunciation fighting`

The CTA variation `اگه می‌خوای` was accepted and did **not** justify another render.

## 4. Duration decision

Final duration:

**8 seconds**

The user explicitly preferred 8 seconds for this concept.

Why it worked:

- compact claim;
- no technical explanation;
- one payoff;
- one CTA;
- reduced pressure on Flow to rush the Persian delivery.

Promoted rule:

> Do not force every talking Reel to 10 seconds. If the complete value proposition naturally fits in 8 seconds, prefer the shorter clean delivery.

## 5. Character experiment failure — ASDEV-SIG-01

Failure reasons:

- facial moles / beauty marks looked especially bad;

`ASDEV-SIG-01 = REJECTED FOR MOTION`

## 8. Generated overlay failure and successful fix

An intermediate render generated unwanted text / graphic elements on top of the video even though the prompt already contained basic `NO TEXT` language.

The successful fix was **not** to redesign the whole prompt. Only the output-mode constraint was strengthened.

### Approved zero-overlay contract

```text
IMPORTANT VISUAL RULE:

This must look like pure raw in-camera footage from a real creator.

Absolutely no added visual elements of any kind.

Do NOT generate:
- subtitles
- captions
- titles
- labels
- lower thirds
- floating text
- Persian text
- English text
- logos
- brand marks
- watermarks
- stickers
- icons
- buttons
- decorative UI
- browser UI
- app UI
- social media UI
- popups
- frames
- callout graphics

Do NOT place any word or symbol anywhere in the frame,
including on the background, screens, walls, desk items, clothing, or as overlays.

No intro card.
No outro card.
No text at the beginning.
No text at the end.

Every visible element must be a normal physical object in the studio scene only.
```

### Clean raw footage reinforcement

```text
CLEAN RAW FOOTAGE:

The result must look like untouched raw camera footage.

There must be ZERO on-screen graphic design.

No subtitles.
No captions.
No on-screen text.
No words anywhere in the image.
No Persian typography.
No English typography.
No logo.
No watermark.
No sticker.
No icon.
No arrows.
No interface.
No visual overlay.
No lower-third.
No intro or outro title.

If a background object could accidentally appear like text, keep it abstract, blurred, or remove it.

Only the real woman and the physical studio scene should be visible.
```

Result: the final render contained no unwanted overlay/UI/text and was explicitly approved.

Promoted rule:

> When Flow invents graphics, fix only the output-mode contract. Do not destroy an otherwise successful character/performance prompt.

## 13. Failure summary

### F-01 — Sora 2 spoken pronunciation

Symptom: Flow pronounced `2` badly.

Fix: remove the number from speech entirely.

Learning: do not spend credits fighting a non-essential number.

### F-02 — ASDEV-SIG-01 artificial in motion

Symptom: static character looked good, motion character looked artificial; face moles were especially undesirable.

Fix: reject the new motion identity and return to canonical Rose.

Learning: static character approval does not equal motion approval.

### F-03 — unwanted generated text / graphics

Symptom: Flow added text/graphic elements despite basic no-text instructions.

Fix: strengthen the raw-camera / zero-overlay output contract only.

Learning: `NO TEXT` is weaker than explicitly defining the output as untouched raw camera footage with no post-production layer.

### F-04 — overcorrecting accepted output

The final render said `اگه می‌خوای` rather than the intended `اگه میخوایش`.

User accepted it.

Learning: do not rerender a strong clip for a harmless natural-language variation that preserves the CTA meaning.
