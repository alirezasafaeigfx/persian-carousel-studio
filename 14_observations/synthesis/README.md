# Observation Synthesis

Periodic system review only.

## SYN-010

After 10 meaningful observations, review:

- repeated defects;
- rules that fail to enforce;
- rules that create friction;
- visual repetition;
- copy/tone drift;
- category weakness;
- unused files;
- hot-path growth/context inefficiency.

Output: `SYN-010-production-review.md`

## SYN-020

After 20 meaningful observations, review:

- recurring approval/rejection patterns;
- art-direction patterns that generalize;
- hook/copy patterns with repeated human approval;
- recurring production friction;
- evidence for/against Phase 4;
- opportunities to remove/compress rules, not only add them.

Output: `SYN-020-learning-review.md`

Neither synthesis automatically changes canonical architecture. Governance gates still apply.
