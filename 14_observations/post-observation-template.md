# Post Observation Template

Use one compact record per meaningful production outcome.

```text
ID: OBS-NNN
Date: YYYY-MM-DD
Topic:
Category:
Marketing Job:
Selected Direction:
Slide Count:

Outcome: accepted | revise | rejected
Human Score: optional — user-supplied only

Strengths:
- concrete observation only

Defects:
- concrete observation only

Existing Rule Failed: yes | no | unclear
Regression Candidate: yes | no | unclear
New Rule Needed: yes | no | unclear

Visual Fingerprint:
- Palette Family:
- Typography Strategy:
- Layout Family:
- Visual Mode / Image Treatment:
- Density: low | medium | high
- Framing Strength: F0 | F1 | F2 | F3 | mixed

Copy Fingerprint:
- Hook Architecture:
- Tone / Colloquiality:
- CTA Family:

Performance Data:
- unavailable
# Replace only with explicit user-provided metrics/evidence.

Promotions:
- Feedback Ledger: none | FB-NNN
- Regression: none | REG-NNN
- Gold Standard Candidate: none | GS candidate reference

Notes:
- short operational note only
```

Rules:

- compact enough to scan without source chat;
- Human Score only when user explicitly supplies it;
- performance defaults to unavailable;
- no chain-of-thought, full transcript or invented data;
- Observation is evidence, not canonical rule.
