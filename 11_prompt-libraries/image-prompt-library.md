# Image Prompt Library

Use modular prompt architectures. Do not rely on vague adjectives as the design system.

## Prompt layers

1. canvas / aspect ratio
2. semantic purpose of the slide
3. composition / regions
4. primary visual function
5. image treatment
6. design foundation snapshot
7. exact-text authority rule
8. exclusions

## Useful architectures

### Typography-led

Use for decisive cover/reframe slides where type is the visual object.

### Diagram-led

Use for processes, systems, comparisons and causal explanations.

### Object / 3D-led

Use when an object/metaphor can communicate the concept faster than text; avoid decorative 3D with no semantic role.

### Evidence-led

Use real/product-native screenshot evidence when available and useful. Do not fabricate screenshots that look like factual product UI.

### Mixed editorial

Combine one clear editorial headline system with one meaningful visual mode and restrained annotations.

## Negative prompting / exclusions

When not semantically justified, avoid:

- generic neon AI aesthetic;
- humanoid robots;
- glowing brains;
- excessive glass cards;
- random tech glyphs;
- decorative arrows that imply no relation;
- fake product screenshots.

## Persian safety

Generated artwork should not be the final authority for critical Persian text. Final production should use exact/hybrid typography where possible.
