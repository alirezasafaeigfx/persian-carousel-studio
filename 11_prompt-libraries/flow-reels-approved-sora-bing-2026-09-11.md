**Duration:** 8s

## Render note

The accepted final render did not reproduce the final CTA wording perfectly. It naturally said:

```text
«اگه می‌خوای، سورا رو کامنت کن.»
```

instead of:

```text
«اگه میخوایش، سورا رو کامنت کن.»
```

The user accepted the render and no retry was needed.

This does **not** mean Flow's exact-dialogue constraint is guaranteed. It means the small variation was harmless in this instance.

## P-SORA-002 — Number Removal for Unstable Product Version Pronunciation

**Status:** `APPROVED-PATTERN`

Initial spoken copy included `Sora 2`.

Flow pronounced the number badly.

Successful correction:

```text
Do NOT say “Sora 2”.
```

Then simplify the dialogue to the product family name only:

```text
«برای سورا پول نده!»
```

### Rule

When a product-version number is not essential to comprehension and pronunciation becomes unstable:

`remove the number from speech rather than over-engineering pronunciation`

The version number can still appear in manually designed cover/caption copy when factually correct.
