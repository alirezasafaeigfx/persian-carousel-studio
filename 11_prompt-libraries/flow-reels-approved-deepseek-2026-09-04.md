## Demonstrated failure fixes embedded in this baseline

- `نت جهانی` repeatedly became `نَت جهانی` → rewrite to `اینترنت جهانی`.
- `هوش مصنوعی` once became `هوش مصنعی` → targeted pronunciation lock.
- mid-video reset/jump near ~3.88s → `ONE SINGLE UNINTERRUPTED 10-SECOND RECORDING`, locked camera, explicit no-reset contract, critical continuity window 3.50–4.30s.
- over-textured skin → clear healthy natural skin contract, no visible acne/prominent freckles/heavy texture.
- corporate male character felt synthetic → Lia organic creator direction.

## Reuse rule

این prompt را برای Reel بعدی کپیِ کور نکن. Patternهای دائمی آن را reuse کن:

1. micro lead-in 0.2–0.3s
2. real silence inside the same take
3. locked camera when continuity is fragile
4. targeted pronunciation locks only after demonstrated failure
5. lexical rewrite when phonetic correction repeatedly fails
6. final success test tied to observed artifacts

Claim-specific text و product-specific pronunciation باید هر بار جداگانه verify و adapt شود.
