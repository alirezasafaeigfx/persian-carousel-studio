# Persian Style Guide

## Default

Write natural, fluent Persian for Instagram. Meaning comes before literal translation.

Priority:

`meaning → natural Persian → clarity → rhythm → persuasion → brevity`

## Orthography

- Use Persian punctuation in Persian sentences.
- Keep نیم‌فاصله where natural and reliable.
- Keep terminology consistent within one carousel.
- Avoid awkward literal English syntax.
- Avoid excessive slang.

## Mixed Persian / Latin

Latin/code/product tokens are valid when they improve precision, but do not create unsafe hybrid morphology.

Unsafe generated forms:

- `promptت`
- `GPTها`
- `ChatGPTرو`
- `toolها`

Prefer natural Persian or separated constructions:

- «پرامپتت»
- «GPTها» only in exact-text composition with bidi isolation, otherwise «مدل‌های GPT»
- «ChatGPT رو»
- «ابزارها»

## Bidi writing rule

Critical Latin/code tokens should be treated as atomic LTR units in final composition. Punctuation belonging to the LTR token stays inside the isolated span.

## Exact-copy rule

Once Exact Persian Copy is approved/locked, later visual stages must not silently rewrite it.

Generated Persian inside image artwork is not authoritative final copy.
