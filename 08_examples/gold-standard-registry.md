# Gold Standard Registry

Gold Standards are **scoped evidence**, not templates.

## Retrieval rule

Default maximum: `2` relevant Gold Standards.

Retrieve only when the current task benefits from known evidence. Do not load the whole example library.

## Interpretation rule

A Gold Standard may validate dimensions such as:

- hierarchy;
- coherence;
- whitespace behavior;
- visual storytelling;
- narrative pacing;
- exact-text discipline.

It does not automatically canonicalize:

- palette;
- font;
- motif;
- card geometry;
- illustration style;
- one layout.
