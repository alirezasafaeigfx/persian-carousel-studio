# Category Art Direction System

Category defines a **visual territory**, not a template.

## CAT-01 — Educational / How-to

Favors:

- progression;
- annotated examples;
- process flows;
- diagrams;
- before/after logic;
- readable utility.

## CAT-02 — Tools / Comparison / Selection

Favors:

- product evidence;
- feature framing;
- comparison structures;
- selection logic;
- UI/evidence-led treatment when appropriate.

## CAT-03 — Analysis / Future / Opinion

Favors:

- editorial tension;
- conceptual metaphor;
- evidence/quote/data hierarchy;
- more interpretive visual storytelling.

## CAT-04 — Efficiency / Cost / Operations

Favors:

- systems/process diagrams;
- operational flows;
- constraints/trade-offs;
- evidence-neutral presentation.

## CAT-05 — Proof / Build / Case Study

Favors:

- real screenshots/evidence;
- sequence from problem to implementation/result;
- artifact-led storytelling;
- source clarity.

## CAT-06 — Founder / Personal Perspective

Favors:

- human/editorial treatment;
- opinion framing;
- direct voice;
- selective portrait/personal evidence when available.

## Anti-template rule

No category may permanently map to one fixed palette, font, grid composition, card system or motif.
