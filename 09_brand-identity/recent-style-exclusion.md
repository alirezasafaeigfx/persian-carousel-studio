# Recent Style Exclusion

Purpose: reduce accidental repetition across recent posts without turning diversity into randomness.

## Evidence source

Use only real recent output metadata supplied in the task or the warm-memory file:

`14_observations/recent-post-index.md`

Do not read individual historical OBS files for ordinary carousel generation.

## Comparison dimensions

Check the last 2–3 relevant posts, up to the five-entry index window, for repeated dominant combinations of:

- palette family;
- typography strategy;
- layout family;
- visual mode / image treatment;
- density;
- framing.

## Decision

If a proposed post repeats the same dominant combination, reconsider at least one meaningful dimension unless:

- the posts are intentionally a series;
- product-native visuals require it;
- brand/semantic continuity clearly benefits from repetition.

If evidence is unavailable:

`Recent-style conflict: unavailable`

Never infer or invent history.
