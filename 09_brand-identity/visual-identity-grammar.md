# Visual Identity Grammar

ASDEV visual identity is defined by **Invariants + Controlled Variables**.

## Invariants

- Persian-first communication;
- decisive hierarchy;
- editorial restraint;
- meaningful whitespace;
- accent discipline;
- functional decoration;
- visual specificity;
- continuity by grammar, not template;
- exact-text safety;
- evidence-aware claims.

## Controlled Variables

- palette family;
- background treatment;
- typography dominance;
- layout family;
- motif;
- density rhythm;
- image treatment;
- framing strength.

## Core rules

`هویت ثابت ≠ layout ثابت`

Accent hue is not globally fixed.

Do not repeat dominant layout combinations mechanically across posts.

## Generic AI risk

Default suspicion applies to:

- cyan/purple neon;
- glowing brains;
- humanoid robots;
- random glass cards;
- rocket=growth;
- bulb=idea;
- puzzle/chess=strategy.

Use only when the content genuinely requires them.

## Identity review

Ask:

- Does the post feel deliberate and specific?
- Is the ASDEV signature present without overpowering the message?
- Is the visual language coherent within the set?
- Is the post different enough from recent outputs when evidence exists?
- Has a successful old surface style been mistaken for brand identity?
