# CTA Copy System

Write CTA copy only after the marketing job and audience end state are clear.

## Utility

Examples of behavior:

- «دفعه بعد این مرحله رو امتحان کن.»
- «برای تصمیم بعدی این معیارها رو کنار هم بذار.»

## Discussion

Ask one real, answerable question tied to the content.

## Navigation

State exactly where to go and why, without confusing mixed-direction instructions.

## Conversion

Keep it specific, qualified and low-friction.

## Avoid

- stacked CTAs;
- engagement begging;
- fake urgency;
- vague «نظرت چیه؟» when the post provides no real discussion frame.
