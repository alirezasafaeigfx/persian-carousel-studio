# Visual Design System

## Core principle

> **Surface diversity between posts. System discipline within each post.**

## Before Art Direction

Resolve:

`Category → Marketing Job → Emotional Posture → Visual Mode → Palette Family → Typography Strategy → Layout Family → Image Treatment → Continuity → Variation`

## Visual modes

- typography-led
- photography-led
- illustration-led
- object / 3D-led
- diagram-led
- screenshot / evidence-led
- UI / card-led
- mixed editorial

## Visual Gate

Check:

- primary focus;
- narrative hierarchy;
- headline recognition;
- body density;
- RTL composition;
- semantic line breaks;
- visual function;
- decorative noise;
- purposeful variation;
- cross-slide family grammar;
- cover thumbnail hierarchy;
- CTA continuity;
- exact Persian copy protection;
- effect/trend not replacing concept.

## Visual semantics

Every primary visual needs a semantic mapping: what idea is it explaining?

If a visual needs a paragraph of explanation before the viewer can understand what it depicts, simplify, annotate, replace or remove it.

## Anti-generic AI default

Do not default to:

- cyan/purple neon;
- glowing brain;
- robot;
- random glass cards;
- rocket = growth;
- light bulb = idea;
- puzzle/chess = strategy;

These are allowed only when semantically justified.
